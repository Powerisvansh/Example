# Luxe Estates — Ultra Luxury Real Estate

A cinematic, dark-themed luxury real estate website built with pure HTML, CSS, and JavaScript. Designed with glassmorphism, 3D depth effects, and a high-end editorial aesthetic.

## Features

- Cinematic hero section with full-screen background and animated stats
- Glassmorphism cards with 3D mouse-tracking tilt effect
- Featured property listings with badge labels and enquiry CTAs
- Architecture showcase with layered depth image grid
- Investment CTA section with parallax-style backdrop
- Fully functional FAQ accordion
- Professional contact form with styled inputs and SVG icons
- Newsletter subscription in footer
- Custom white cursor with smooth trailing ring
- Scroll indicator animation
- Fully responsive — mobile, tablet, desktop
- Smooth scroll and mobile hamburger menu

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Powerisvansh/Example.git

# Open in browser
cd Example
start index.html
```

No build tools or dependencies required. Pure HTML/CSS/JS.
